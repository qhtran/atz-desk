# Color tokens (FireAnt-style)

Nguồn code: `src/atz/ui/theme_tokens.py`

| Token | Hex | Ý nghĩa |
|-------|-----|---------|
| `UP` | `#00C087` | Tăng / lãi / tích cực |
| `DOWN` | `#E53935` | Giảm / lỗ / tiêu cực |
| `REF` | `#FFC107` | Tham chiếu / không đổi / nền cột giá mua |
| `BG_PRIMARY` | `#121418` | Nền app (mục tiêu) |
| `BG_CARD` | `#1E232A` | Nền thẻ |
| `CEILING` / `FLOOR` | tím / cyan | Trần / sàn — dự phòng, chưa dùng rộng |

Đã áp: Quản trị vị thế, Tổng quan (chỉ số), Realtime (bảng giá + P&L), thẻ chỉ số, Top 20 (RS), `config.CHART` UP/DOWN.
